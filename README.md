## 🚀 What I'm building

- **🤖 [Avina](https://www.avina.io/) · [YC S22](https://www.ycombinator.com/companies/avina)** — My main gig as co-founder & CTO. We build AI agents that help B2B teams figure out who to reach out to, why now, and what to say.

- **🛠️ [Macrofold](https://github.com/Macrofold/Macrofold)** — Open-source infrastructure for AI agents with persistent cloud workspaces. Run agents in the cloud without making them start from scratch every time.

- **🌍 [Open Legend](https://github.com/Macrofold/OpenLegend)** — An early game/simulation exploring characters with memory and agency, and worlds that grow through play. This is what happens when my interests in AI, psychology, and RPGs end up in the same project.

Previously, I co-founded **Bowtie**, an AI receptionist [acquired by Mindbody in 2019](https://tech.cornell.edu/news/bowtie-acquired-by-mindbody/).
